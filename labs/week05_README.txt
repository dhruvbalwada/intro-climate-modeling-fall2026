Week 5: Forcing, feedback, and Gregory plots (October 8, 2026)

Unzip this folder and open gregory_cmip6.ipynb in Jupyter.
Run the notebook from its containing folder. Keep data/ beside the notebook.

The two-box ocean and regional heat-transport labs move to Week 6 (October 15).
Download those notebooks from the Week 6 section of the course Labs page.

The Gregory notebook defaults to reading CMIP6 fields from the cloud. To use
our supplied annual means instead, set USE_SAVED_MEANS = True in its setup cell.
The CSV and provenance JSON must stay together in data/.

Use the course LEAP Python environment. If packages are missing, install from
week05_requirements.txt in your Python environment. Jupyter/IPython is also
needed. These package versions were used for local checks; LEAP environments
may already provide suitable versions.

Save your work in your private course repository. Follow the instructor's
in-class guidance for which exercises to complete.
